# Programa-o-em-Intelig-ncia-Artificial-IA-Generativa
Projetos Práticos - IA Generativa (SENAI) Repositório com as atividades do curso de Programação em IA Generativa no SENAI. O objetivo é aplicar ferramentas de Inteligência Artificial Generativa no apoio à lógica de programação, desenvolvimento de código e criação de soluções funcionais na prática.
