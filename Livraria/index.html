UM NOVO CAPÍTULO

Atualizar base de vendas

Selecione a planilha CSV completa. Ela substituirá a base atual e atualizará todos os indicadores.

Como preparar seu arquivo

Use as colunas Data, Loja, Categoria, Produto, Quantidade, Valor. Data no formato 2026-08-26. Valor é o total da venda, não o preço unitário.

Aceitamos separador vírgula ou ponto e vírgula, com valores como 59.80 ou 59,80 (entre aspas se o separador for vírgula).

Os dados ficam neste navegador. Guarde seu CSV para atualizar a base ou abri-la em outro dispositivo.
